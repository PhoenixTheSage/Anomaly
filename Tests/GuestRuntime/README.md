# Vulkan guest runtime regression

After the canonical Anomaly Release build, add `--core` to load the actual net10.0 core assembly and check its planet snapshot/radii API, double center, opaque terrain radius, stale-snapshot clear and absence of DX11 references. This fixture injects a CPU snapshot; loaded-game planet selection remains a live acceptance item. Volume frame tests verify shared struct sizes/provider bytes, rotated reversed projection, dt clamping and camera history rejection.

The GPU lane now uses the production batch serializer for the complete shared light/inject/integrate/reconstruct/reactive chain. Invalid native and managed tails must leave their valid prefix unqueued and preserve earlier accepted work. The native queue reserves capacity before commit. These checks prove queue atomicity and kernel pixels, not active provider interval ownership.

The extended volume lane compiles the production shared light, injection, integration, two-target reconstruction and reactive-coverage shaders using a controlled emissive provider. It checks feature-512 failure/recovery without recompilation. GPU replay checks five outputs over partial 9×3×5 groups, t43 and high b6/b7 fields, byte-copy isolation, rejected missing/aliased/duplicate/mismatched-format resources, R16F optical depth, analytic emission/transmittance/reject coverage and D32 comparison sampling. Native validates storage-image formats/dimensions against SPIR-V. The fixture supplies synthetic shadow/interior/history inputs; this is resource/kernel evidence, not live shared-renderer activation or full producer parity. With --packs, the production Final Frontier fog and cloud providers also obtain extended light/injection/reconstruction pipelines individually and in both provider orders. Pipeline creation and packet serialization use the production NativeBackend extended partial. The DX11 Volumetrics suite separately passes 113 contract, HLSL and WARP checks.

Requires .NET 10, the sibling SE-Vulkan source tree and its bundled compiler tools. Override the source location with `-p:VulkanRoot=...`. Override game assembly references with `-p:Bin64=...`. Set `SE_GAME_CONTENT` to the installed game's Content folder when using another workstation.

From the Anomaly repository:

```powershell
dotnet run --project Tests/GuestRuntime -c Release -- .
dotnet run --project Tests/GuestRuntime -c Release -- . --packs --gpu
```

The base lane compiles all ten owned programs with the real compiler, verifies renderer-unavailable recovery without recompiling, and verifies terminal HLSL diagnostics. Production GuestBridgeClient drives a recording renderer/catalog fixture to check scene resolution, Hi-Z size, depth ping-pong and history invalidation on resize. Lit-mip checks cover explicit/automatic demand, sticky maximum, producer order, small-size clamping, disabling consumers and missing native capability/recovery. Occupancy checks cover demand/features/scene gating, current-depth provenance, output/dispatch dimensions, world-box exclusions and large-coordinate subtraction, incumbent selection and bounded work. Those packet checks are not GPU execution evidence.

`--packs` requires the sibling Prism.SSGI, VolumetricClouds, se-aurora, ScreenSpaceShadows and FinalFrontier sources. It verifies manifest binds and requires every pack program to obtain a pipeline. `--gpu` uses the freshly built Release native library when available, otherwise the packaged native asset. It requires a real offscreen Vulkan device and pipelines for every program, checks a 1280-byte stock frame CB with UV gradient pixels, and rejects validation errors. Build native assets with SE-Vulkan's canonical `scripts/build-native.ps1 -Configuration Release -Deploy` first. Missing assets/hardware fail this strict lane.

The strict GPU lane also uploads an FP16 HDR checkerboard, replays production native mip generation, and samples LOD 1/2/3 into an RGBA8 readback. Values above one must survive the FP16 pyramid and produce the expected averages. Fractional LOD 0.5 verifies interpolation between levels. Replacing the source then verifies refreshed base/all mip values. The lane requires the native feature getter to advertise flag 8; rebuild the native library before running it. Managed demand checks also exercise the LitMips debug-view request.

The occupancy GPU lane uses the production shaders and native packet replay. It compares all 262,144 atlas cells against an independent CPU oracle for rotated/jittered depth at 9×3 (partial workgroups), 65 box stamps, changed box data and next-frame clearing. A separate structured read checks the first and 65th box plus copied b0 values. The two-pass case reproduced an unaligned second UBO before guest allocation used device alignment independently of the world pipeline; it now passes. Native feature flags 16/32 are required.

The point-shadow lane drives the production managed owner and native replay, with copied stock-equation skinning, six lights and all cube faces, animated pose changes, optional world boxes and render-sized player depth. Independent ray/box oracles check full image pixels; a million-metre observer move must leave atlas geometry bytes identical. It also checks header validity, missing capabilities, spectator clears, resize, four-bone/homogeneous skinning, unused vertices and the actual `AnomalyPointShadows.hlsli` consumer. Features 32/64/128/256 are required.

These checks do not replace live captures comparing pack output with DX11, nor prove loaded-world geometry coverage, device recreation or performance. The shared froxel volumeReactive producer remains parity work. Requested lit mips, occupancy and the character atlas/playerDepth have producer and GPU-pixel coverage.

Initial activation evidence on 2026-10-16, before the lit-mip/occupancy follow-ups: NVIDIA GeForce RTX 5070 Ti accepted all 30 initial pipelines (five owned, 21 manifest pack programs, three Final Frontier programs, one stock-frame probe), stock-frame/UV pixel readback, recorded catalog/binding/order/history checks, shader error reporting and delayed renderer retry. Native ABI/GPU smoke and the existing GuestDraw fixtures passed. Vulkan validation layers were unavailable (`validation_enabled=0`); these results do not claim validation-layer coverage. Those initial Anomaly and SE-Vulkan Release net48/net10 builds were deployed to local Pulsar folders. Later producer follow-ups have the additional checks described above; their validation does not itself deploy new binaries.

The CPU routing lane now uses the production core volume facade, state machine and reflection bridge, plus a separate companion fixture compiled from the production DX11 CPU registry. It verifies pending requests/configuration/copied parameters and double origins, callback identity, cancellation/removal, last-write replay after companion initialization, idempotent replay and exclusive post-commit forwarding. Frame checks revoke old intervals/catalog products on callback or bridge-reset failure and verify recovery. Disabled late fallback presents and source replacement are covered. The common interior packer is checked for sorted signed cells, bounds, cached topology, stale snapshots and double-relative transforms; GPU execution of the production volume kernels verifies sealed-room suppression and restored emission after opening the room. These fixtures do not establish live topology coverage or active shared-renderer parity.

The live resource-phase regression requires feature 1024. It opens an actual native menu frame, creates ordinary and extended pipelines, creates/uploads/replaces a guest image and queues a packet before EndFrame. It then uses explicit replay and pixel readback to verify the created resources. This reproduces the normal callback's allocation timing; it does not prove queued-world insertion. Shared VolumeShadowViews checks receiver and far planes, pole orientation, sub-texel stability, sunward offscreen caster inclusion and large-coordinate relative transforms. DX11's directional producer consumes this same policy source.
