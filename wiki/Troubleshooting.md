# Troubleshooting

In-game: Anomaly settings → **Show Status** for framework health. Use Velocity Debug → **Velocity Status** for motion-vector output and opt-in proofing. Also check `SpaceEngineers.log` and Anomaly’s debug log. Compile errors include `pack=id`.

Known renderer-plugin conflicts and migration requirements are tracked in [[Compatibility]]. Test Anomaly's renderer work with unrelated render plugins disabled.

| Symptom | Likely cause | What to do |
|---------|--------------|------------|
| Pulsar `-sources` / PluginHub CS0122 on `nameof(Type.Method)` | Pulsar Roslyn skips publicizing virtual methods; Krafs used to hide that in IDE builds | Use a string Harmony target (`"Begin"`). Local Publicizer matches Pulsar (`IncludeVirtualMembers=false`). |
| Compile intercept: not live | Hook failed or assets not loaded | Confirm Pulsar 2.4.0 called `LoadAssets`; `Anomaly.xml` must use `Asset Name=AssetFolder Path=Assets/`. |
| Keen GBuffer patch: disabled | A hashed Keen shader changed (game update) or `ShadersPath` was missing | Status names the file and hash. GBuffer velocity is off; camera velocity still publishes. Update Anomaly hashes and anchors for that game build. |
| Compile intercept is live but injected GBuffer output stays unchanged | Shader objects may predate Anomaly or Keen's resident refresh has not run | Rebuild and restart. Status should reach `resident=done#N` after the first refresh for this fingerprint. A second `LoadAssets` with the same packs skips `ReloadEffects`; the last done generation is expected. `Shader overlay opens` and `overlay-GBuffer-PS=N` should be nonzero. `MrtWrite` must then color geometry immediately. |
| World-load hang at the end, or shaders pop in after the world is visible | Compile work used to sit on the render thread serially (DXBC audit, stage probes under `Gate`, lazy `EnsureShaders`, Keen `Recompile`) | Rebuild. Release never reflects or disassembles. `ReloadEffects` runs only when the pack fingerprint or Keen patches change. Stage probes and Keen Recompile bytecode use `Parallel.For` (max 8). `ShaderWarmup` creates Anomaly/pack programs before first present. |
| `DXGI_ERROR_DEVICE_REMOVED` immediately after resident refresh / first GBuffer frame | An old build either mapped Keen's global immediate context from a prepare worker or directly replaced shaders at a scheduler boundary | Rebuild. Prepare is CPU-only and resident replacement now uses Keen's `ReloadEffects` render message. |
| `DXGI_ERROR_DEVICE_REMOVED` after changing velocity probes | An old build compiled `MrtWrite` into the PS and rebuilt all resident shaders on a dropdown transition | Rebuild. Every probe is now runtime-selected through VS b6 / PS b7 and never recompiles or disposes shader objects. |
| Crash finishing world load (`construct_matrix_43`) | GBuffer PS compiled Keen’s VS-only helper | Rebuild Anomaly so `Anomaly.hlsli` deploys. Velocity reconstruct is VS-only (`ANOMALY_PIXEL_STAGE`). |
| Crash finishing world load (`AnomalyInitAttachments` / X3508) | Empty `inout GbufferOutput` — FXC requires every `SV_Target` field written | Rebuild so `GBufferWrite` / generated `GBufferAttachmentInit.hlsli` zero the struct. Hits old pipeline, Decals, Foliage, Sprites. |
| Crash finishing world load (`Destination array was not long enough` in `ActorHistory`) | Stage 2 and old-pipeline snapshots both wrote `Current` on Parallel.Scheduler | Rebuild. Snapshots share a lock; once-per-frame flags do not serialize the two pipelines. |
| Crash finishing world load with DLSS + HDR (`NullReferenceException` in `DrawGameScene` after AfterTonemap; `DeviceRemovedReason=0`) | Unique upscaler skipped `MyToneMapping.Run` without setting `__result`. Keen then reads `borrowedCustomTexture.Linear` / `.SRgb`. | Rebuild Anomaly. Postfix adopts the notified AfterUpscale dest (or borrows the Display wrap) when `Run` returns null. Upscalers should still assign `__result` when they skip. |
| Thread CPU Load ~5–11 ms above vanilla | `Thread CPU Load` is `Parallel.Scheduler` (all workers), not the GPU. A Harmony Prefix on `MyGBufferPass.RecordCommandsInternal` ran for every voxel proxy; forked `Begin` `MapDiscard`ed the velocity CB under a global lock. | Rebuild this slice. The transpiler skips voxels and the per-context CB-ring lock never serializes independent Stage 2 workers. A/B **CameraOnly** if leftover is the 4th GBuffer MRT. |
| Depth / shadows broken | Pack overlay added a target or failed a sentinel | Status `rolled-back=N`. Remove exclusive GBuffer overlay or fix HLSL. |
| Pack missing from Status | Register used `Plugin.Instance` or ran before Anomaly loaded | Register on static `ShaderPackRegistry` from `LoadAssets`. |
| Rich HUD: waiting / idle; no **Anomaly Shaders** in the terminal | Master workshop `1965654081` is not in the world, or handshake has not run | Enable Rich HUD Master for that world. Pulsar MyGui still has the same options. Status `pages=` lists queued titles. |
| Rich HUD pages vanish mid-session on Pulsar Interim (.NET 10); Legacy.exe is fine; world reload restores them | Master's `is ExtendedClientData` / client's `is ServerData` can fail across plugin ALCs. A Master/client reload then left `initAttempted` set so we never `Init` again. | Rebuild Anomaly (and SE-DLSS if standalone). Status should return to `registered` within ~2s without a reload. Log: `[RHF] Successfully registered` or `payload was not ServerData`. |
| F2 works, then the terminal closes within seconds of opening **Anomaly** settings (next F2 restores, then fails again); Legacy.exe is fine | Master's `TerminalValue.Update` invoked `CustomValueGetter` every tick while the page was visible. Dropdown getters return client `EntryData` (Master's `TValue` is `ListBoxEntry`); a bound getter `InvalidCastException`s and `ExceptionHandler` reloads. Checkbox/color `Func`s bind and call into the plugin ALC every tick. Re-handshake only restores F2. | Rebuild Anomaly. Host pages are push-only (no `CustomValueGetter`). Log: `[Anomaly Shaders] RHF exception:` or `Anomaly Rich HUD dropdown`. DEBUG: `Anomaly.debug.log`. |
| Pack page missing under **Anomaly Shaders** | `RequestPage` used a reserved title, ran on `Plugin.Instance`, or Master is absent | Use a unique title beside **Anomaly**. Register on static `TerminalConfigRegistry` from `LoadAssets` / `Init`. Reserved: `Anomaly`, `Settings`, `Velocity Debug`. |
| Corner overlay missing | Master is absent, `HudOverlayRegistry.Register` ran before Anomaly loaded, or the getter returned null | Register on the static type from `LoadAssets` / `Init`. Status `overlays=` lists ids when Master is registered. Getter must return a cached non-empty string. An empty getter only hides that line; the panel stays live so a later string can appear. |
| `DXGI_ERROR_DEVICE_REMOVED` / `DEVICE_HUNG` after dragging or releasing a Rich HUD slider (Pulsar MyGui is fine) | XML / `.cfg` on the HUD or Update thread, or Master `CustomValueGetter` on a float slider (percent round-trip retriggers `ControlChanged` / `SetText` after mouse-up) | Mark dirty in the setter. Cache one serializer. `FlushPending` from `Plugin.Update` must queue the write on a worker. Do not set `CustomValueGetter` on float sliders. See [TerminalConfig.md](../Docs/TerminalConfig.md). |
| `DEVICE_HUNG` after ~1 min with Aurora (pause menu is enough); Anomaly without Aurora is fine | `reactiveMask` clear used `MyRender11.RC` while AfterAtmosphere recorded on Keen’s transparent deferred worker. D3D11 immediate contexts are single-threaded. GC / Keen texture counts stay flat — not a pack texture leak. | Rebuild Anomaly. IsolatedAdd + Reactive now clear/stamp on the slot `rc`. Pack C# that still reads `MyRender11.RC` / `Device.ImmediateContext` from AfterLighting / AfterAtmosphere / AfterTransparent is redirected to the slot `rc` (one log line). Prefer `ctx.Rc`. Trail shows `aurora.borealis.curtain` completing; detection at GBufferVelocity / Present is the wrapper. |
| GPU hang / TDR; Keen log only shows `DEVICE_REMOVED` at `Present` | GPU work is async. `try/catch` around a `Draw` that already returned cannot name the hung shader. | Search `SpaceEngineers.log` for `Anomaly RenderTrace dump at`. Trail is last-N submits (`>` begin, `<` end). A name with `>` and no `<` was in-flight on the CPU. Aftermath `Get Info fail` is common and not a diagnosis. |
| GPU hang diving or slamming a camera into a fullscreen curtain (spectator) | Every pixel pays a large march when the volume fills the view. A global `max(AnomalySafetyScale, 0.25)` floor keeps ~25% of that budget during a slam. Per-ray `tMin` cheapening leaves grazing chords on the compile-time max, and a warp runs that max. | `AnomalyMarchSteps` from camera-to-volume distance (uniform). Do not floor SafetyScale. Keep a few steps when far so the volume does not vanish (`ContributeVelocity` + packed hit `t`). Cap loops with a `#define` integer; `Anomaly fullscreen lint` warns on `while` / dynamic `for`. |
| Frame hitch + grain while slamming spectator through a curtain | Instant `AnomalySafetyScale` tracked spectator meters/frame. A heavy frame made the next camera delta larger, steps collapsed, the cheap frame let scale spring back — GPU load and undersampling grain pulsed together. `Hash21(pos + (frame&7))` only had 8 patterns, so DLSS could not hide the 4-step march. | Rebuild Anomaly (SafetyScale drops immediately, recovers `1/16` per frame) and Aurora (Cranley-Patterson dither over 1024 frames). |
| Magenta debug overlay (geometry, full screen) | `HistoryValid` false | First frame, camera cut (~80 m), or a real resize. Status reports it. Sky stays dark grey. |
| Debug velocity flashes magenta and light blue/white when looking around | Camera-from-depth on complementary-zero sky saturates the colormap (+X → magenta, +Y → cyan, both → white) | Rebuild and restart so `CatalogDebug.hlsl` recompiles. Overlay paints complementary-depth 0 dark grey; the catalog texture still holds those sky MVs for consumers. |
| Debug velocity paints ships as sky (dark, no silhouettes) | Overlay used `hw < 1e-5` as sky. Complementary geometry is `hw > 0`; distant hulls are smaller than 1e-5. | Rebuild and restart. Sky is complementary 0 only (`IsDepthForeground`). |
| Moving ships stay mid-gray in debug velocity (character in chase-cam may stay grey) | Old-pipeline `HasPrevWorld` rows were a previous world matrix; the VS inverted `local_matrix` again (or never stored Main-view `m_row0–2` because `ViewId==0` is not Main). Target3 stayed ~0. | Rebuild and restart. Status `local-rows` and `Old-pipeline GBuffer: N/M` should be nonzero. Debug scale 1 is most sensitive. Third-person chase-cam keeps the suit grey; the grid should tint. |
| Character / Stage 2 props stay mid-gray while the camera tracks them; a nearby mover should tint and does not | t15 is packed (`V/S` like `833/833`) but the VS indexed from 0 unless InstanceBase is bound per group. Pause Prepare used to publish `groups=0` while keeping the pack counts. | Close the game, rebuild, restart. Status last-drawn: `groups=` / `drew=` / `base=`. A paused overlay is mid-grey even when pack is correct — look while moving. If `visible=0`, those actors are old-pipeline. |
| `MrtWrite` stays gray | Target3 may be masked, or a shader stage may interpret the wrong constant-buffer layout even when the correct buffer pointer is rebound. | Current builds repair masked Target3 writes, use an Anomaly-owned per-context VS CB ring, and bind a separate immutable 16-byte PS b7 probe. In `GBufferVelocityRaw` + `MrtWrite`: pink proves the full path, matching cyan regions never wrote Target3, and gray grid blocks explicitly wrote zero. Reflected layouts should read VS `cb=240` probe@212 and PS `cb=16` probe@0; probe readback should read VS `2/2` PS `(8,1)/(8,1)`. |

## Status fields that matter

Compile intercept live + include path + resident refresh (queued on Keen render thread, running, `done#N`, or failed). `Shader overlay opens` must show nonzero dispatcher and GBuffer VS/PS counts after refresh. GBuffer bytecode reflects b6, TEXCOORD12, Target3, and the internal Target7 audit output; `blend(write/mask/fix/fail)` reports source masks and repaired draw states. Native draw state `blend(m/n/x)`, independent, and `writable3/7` prove the actual D3D11 eight-target blend descriptor rather than only its managed identity, while `cb-ring=used/capacity` proves distinct per-context constant buffers were available. In `PassEndClear`, `pass-end-clear=1` confirms one final immediate-context clear after all deferred geometry lists. Shader packs / rolled-back. GBuffer attachments. Pass binds. Owned passes. Fullscreen programs. Frame temporal (jitter / history). Camera velocity live. Owned buffers sizes. Velocity buffer WxH, convention, history valid. Old-pipeline GBuffer prev-world draw counts (`hook=` / `voxel=` / `id0=` / `miss=`). Stage 2 t15 packed-valid / groups. Catalog debug mode. `hook=0` means the old-pipeline transpiler never ran. Stage 2 Status is last-drawn per field (pause Prepare must not wipe groups). `V/S` like `833/833` means t15 packed with ActorID history. `drew=` is groups at `MyGeometryRenderer.Render`. `groups=` / `base=` are InstanceBase binds. A paused overlay is mid-grey even when pack is correct.
